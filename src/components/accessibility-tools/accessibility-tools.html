Instruções de acessibilidade

  • Use Tab e Shift + Tab para percorrer links e controles. Pressione Enter ou Espaço para ativar.
  • No menu móvel, pressione Esc para fechar e voltar ao botão do menu.
  • Nos depoimentos, use os botões anterior e próximo ou as bolinhas para escolher uma avaliação. A rotação pausa ao navegar por teclado ou interagir; use “Retomar rotação” para continuar.
  • Para reduzir animações, ative “Reduzir movimento” nas configurações de acessibilidade do seu dispositivo.

Atalhos de teclado

Ctrl + Alt + Shift + 0Início
Ctrl + Alt + Shift + 1Serviços
Ctrl + Alt + Shift + 2Sobre
Ctrl + Alt + Shift + 3Depoimentos
Ctrl + Alt + Shift + 4Dúvidas
Ctrl + Alt + Shift + 5Contato

No Windows e Linux, use Ctrl + Alt + Shift; no Mac, use Command + Option + Shift. Os atalhos precisam de teclado físico; em celulares e tablets, use a navegação visível na tela. Navegadores ou leitores de tela podem reservar algumas combinações.
